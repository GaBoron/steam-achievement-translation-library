# Steam Achievement Translation Library

[简体中文](README.md) | English

A community-maintained repository of translated Steam achievement BIN files, with JSON sidecars and a searchable website for SATLI and SATLI lite.

> [!TIP]
> To download and display translations inside Steam, use [SATLI lite](https://github.com/GaBoron/SATLI-lite). It requires Millennium 3.5.0 or newer and does not require the SATLI desktop client. Use [SATLI](https://github.com/GaBoron/SATLI) to manage local BIN files, prepare submission ZIPs, or back up and restore original files. This repository is for browsing and contributing translations.

## 📚 Library Actions

- **Use translations inside Steam:** Follow the [SATLI lite installation guide](https://github.com/GaBoron/SATLI-lite#安装), open “管理译本” (Manage translations), choose a game, variant, and language, then preview and apply it. No manual BIN download or replacement is required.
- **Find a translation:** Search the [library website](https://gaboron.github.io/steam-achievement-translation-library/?lang=en) by game name, Steam app ID, or contributor, or filter by status and language. Open the game details, choose a variant by its version note, and check for possibly outdated or possibly ineffective status.
- **Request a missing translation:** Open a [translation petition](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_petition_en.yml) and attach the original schema ZIP generated by Steam.
- **Contribute a translation:** Follow the [contribution guide](docs/CONTRIBUTING_EN.md) to [submit a new game](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_contribution_en.yml) or [update an accepted file](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_update_en.yml).
- **Report a problem:** Use the [file issue report](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=outdated_report_en.yml) for an outdated or ineffective translation. Submit an update instead if you already have a replacement.

For direct downloads, make sure the file name and app ID match. BIN/ZIP files are for SATLI installation or submissions; V2 translation JSON is for SATLI lite. Renaming an extension does not convert between these formats. Use [SATLI](https://github.com/GaBoron/SATLI) for BIN installation, backup, and recovery to avoid replacing the wrong local file.

## 🧩 Developer Integration

`index-v2.json` is the public game catalog. Each translation lives under `files/<app_id>/<variant_id>/` and includes a complete BIN and display-text JSON. Preview names, descriptions, and languages on the website.

See the [data integration guide](docs/integration.md#english) for catalog fields, download validation, and sample code, and the [translation JSON format](docs/translation-json.md#english) for text fields.

## 🔄 How The Projects Work Together

| Project | Role |
| --- | --- |
| **This repository** | Stores community translations, the catalog, and translation JSON |
| [Steam Achievement Translation Manager](https://github.com/GaBoron/SATLI) | Uses this library to scan, preview, install, edit, back up, and restore files; it can also export submission-ready ZIP files |
| [SATLI lite](https://github.com/GaBoron/SATLI-lite) | Downloads JSON, selects variants and languages, edits local text, and displays translations inside Steam; see [installation and usage](https://github.com/GaBoron/SATLI-lite#安装) |
| [Steam Achievement Localizer Skill](https://github.com/GaBoron/steam-achievement-localizer-skill) | Looks up reference files in this library, researches and produces translations with Codex, and outputs BIN/ZIP files for the manager or this repository |

For a standalone visual editor, see [PanVena/SteamAchievementLocalizer](https://github.com/PanVena/SteamAchievementLocalizer).
