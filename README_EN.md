# Steam Achievement Translation Library

[简体中文](README.md) | English

A community-maintained data repository for translated Steam `UserGameStatsSchema_<app_id>.bin` files, with a searchable index.

> For most users, **Steam Achievement Translation Manager** is the best starting point. It can find, install, edit, back up, and restore translations; this repository is primarily for browsing and contributing data.

## 📚 Library Actions

- **Find a translation:** Search [INDEX_EN.md](INDEX_EN.md) by Steam app ID for the most reliable result. For games with multiple files, choose by the version note and check for possibly outdated or possibly ineffective status.
- **Request a missing translation:** Open a [translation petition](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_petition_en.yml) and attach the original schema ZIP generated by Steam.
- **Contribute a translation:** Follow the [contribution guide](CONTRIBUTING_EN.md) to [submit a new game](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_contribution_en.yml) or [update an accepted file](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=translation_update_en.yml).
- **Report a problem:** Use the [file issue report](https://github.com/GaBoron/steam-achievement-translation-library/issues/new?template=outdated_report_en.yml) for an outdated or ineffective translation. Submit an update instead if you already have a replacement.

For direct downloads, make sure the file name and app ID match. Use [Steam Achievement Translation Manager](https://github.com/GaBoron/steam-achievement-translation-installer) for installation, backup, and recovery to avoid replacing the wrong local file.

## 🔄 How The Projects Work Together

| Project | Role |
| --- | --- |
| **This repository** | Stores community translations, the index, and submission records |
| [Steam Achievement Translation Manager](https://github.com/GaBoron/steam-achievement-translation-installer) | Uses this library to scan, preview, install, edit, back up, and restore files; it can also export submission-ready ZIP files |
| [Steam Achievement Localizer Skill](https://github.com/GaBoron/steam-achievement-localizer-skill) | Looks up reference files in this library, researches and produces translations with Codex, and outputs BIN/ZIP files for the manager or this repository |

For a standalone visual editor, see [PanVena/SteamAchievementLocalizer](https://github.com/PanVena/SteamAchievementLocalizer).
